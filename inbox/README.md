# inbox/

Only used by `scripts/run_brief.py`. Drop newsletters here before you run it:

- `.eml` files (most mail apps can "Save as" or drag a message out)
- `.html` files (a newsletter's "view in browser" page, saved)
- `.txt` or `.md` files (paste the text)

The script reads files changed in the last ~36 hours for a daily brief and the last
7 days for a weekly recap. Everything in this folder except this README is ignored
by git, so your mail never ends up on GitHub.
